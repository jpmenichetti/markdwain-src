# MarkDwain Help

MarkDwain is a read-only Markdown viewer. Every file opens in its own window and refreshes when the file changes.

| Action | Shortcut |
|---|---|
| Open a file | ⌘O |
| Find in page / next / previous | ⌘F / ⌘G / ⇧⌘G |
| Table of contents | ⌃⌘S |
| Zoom in / out / actual size | ⌘+ / ⌘− / ⌘0 |
| Reveal in Finder | ⇧⌘R |

To make MarkDwain open all `.md` files: select a `.md` file in Finder, press ⌘I, choose MarkDwain under *Open with*, then click **Change All…**.

Press Space on a `.md` file in Finder for a Quick Look preview.
